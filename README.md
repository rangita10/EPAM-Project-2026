🏦 My Bank

A simple banking web application built using **HTML, CSS, and JavaScript**. 
It allows users to deposit and withdraw money, apply coupon rewards, view transaction history, and reset the account.

✨ Features

* Deposit & Withdraw Money
* Apply Reward Coupons
* Transaction History
* Account Balance Display
* Reset Account

🛠️ Technologies Used

* HTML
* CSS
* JavaScript

🚀 How to Run

1. Upload your project files (index.html, style.css, and script.js) to a GitHub repository.
2. Open the repository in the GitHub Sandbox.
3. Start the preview or use a simple web server.
4. Open index.html in the browser preview.
